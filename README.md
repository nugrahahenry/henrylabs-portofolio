# HenryLabs Portfolio

Interactive personal portfolio prototype for Henry Nugraha.

## What is inside

- Cosmic scroll opening with a project constellation.
- Progressive Three.js depth layer with a 2D SVG fallback.
- Real project marks for Catmoji, Nalira, Canox, Hengs, and Polara.
- Academic projects, client work, technology stack, and bilingual English/Indonesian copy.
- Reduced-motion support and keyboard-accessible project selection.

## Run locally

Open `henrylabs-useful-worlds.html` in a browser. The prototype is intentionally self-contained; the optional Three.js layer and technology marks load from pinned external CDN URLs, while the semantic project content remains available without them.

## Privacy

Private projects are presented as sanitized portfolio evidence. Internal research, planning documents, certificates, credentials, and runtime data are excluded from this public repository.
