# HenryLabs Portfolio

Interactive personal portfolio for Henry Nugraha, now moving from a single-file prototype into a Next.js experience.

## What is inside

- Cosmic scroll opening with a project constellation.
- Next.js component architecture with Motion-driven camera choreography.
- Progressive Three.js depth layer with an accessible static fallback.
- Real project marks for Catmoji, Nalira, Canox, Hengs, and Polara.
- Academic projects, client work, technology stack, and bilingual English/Indonesian copy.
- Reduced-motion support and keyboard-accessible project selection.

## Run locally

Run `npm install`, then `npm run dev` and open the local URL shown in the terminal. The original `henrylabs-useful-worlds.html` remains as a standalone legacy prototype while the Next.js app is developed.

## Privacy

Private projects are presented as sanitized portfolio evidence. Internal research, planning documents, certificates, credentials, and runtime data are excluded from this public repository. Technology marks currently use pinned Simple Icons CDN URLs; project identity assets are served locally from `public/assets`.
